# AI Agent 入侵了我的日常

## 背景

之前写完技术博客，想同步发小红书和抖音，发现这是个痛点：

- 把长文翻译成短句
- 手动加 emoji 和换行
- 一句句改口语化
- 做图、调排版、切尺寸

一篇文章发三个平台，花 2 小时。

## 解决方案

写了一个 Agent，核心代码就 3 行：

```python
model = OpenAIChatModel(...)
agent = Agent(model, system_prompt=...)
result = agent.run_sync("原文")
```

框架用 PydanticAI，模型用 DeepSeek。

## 效率对比

- 以前：2 小时手动改写
- 现在：5 分钟自动生成

提升了 24 倍效率。

## 具体能力

一个输入，自动返回：
- 小红书版（短句+emoji+3:4配图）
- 公众号版（长文+代码块+引用）
- 抖音版（口播脚本+镜头提示）

## 我的思考

不是 AI 取代了我，是我多了一个数字员工。

人做创意、做判断、做选择。AI 做重复、做格式化、做执行。

这是升级，不是被替代。
