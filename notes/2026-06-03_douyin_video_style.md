# Content Agent 抖音系列视频风格卡

日期：2026-06-03

## 定稿基准

以第 2 期视频为基准：

- 视频工程：`output/douyin_content_agent_ep2/index.html`
- 设计说明：`output/douyin_content_agent_ep2/DESIGN.md`
- 成片：`output/douyin_content_agent_ep2/final.mp4`
- 封面：`output/douyin_content_agent_ep2/cover/content-agent-ep2-cover.png`

## 固定风格

这个系列后续保持“深色技术讲解 + 项目真实迭代日志”的风格。

- 画面不要像课程 PPT，也不要像营销宣传片。
- 保持真实开发日志感：问题、判断、实现、下一步。
- 视觉重点服务叙事，不为了炫技转场而打断口播节奏。

## 固定版式

- 画幅：1080x1920。
- 顶部：`CONTENT AGENT / EPxx` 系列标识。
- 中部：一屏一个核心概念，使用流程、对比、清单、代码窗口表达。
- 底部：黑色半透明大字幕条，承接口播关键句。
- 颜色：青色代表能力和流程推进，橙色代表问题和限制。

## 后续复用规则

制作第 3 期及之后的视频时：

1. 先生成 TTS 和 SRT。
2. 按真实 SRT 时间轴拆 8-10 个场景。
3. 复制第 2 期 `index.html` 的基础视觉结构。
4. 只替换每期的核心图形模块，不重做整体视觉系统。
5. 保持结尾预告下一期，形成连续追更感。
