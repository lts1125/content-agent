# Web UI 风格模板库 (P0-2)

## 背景/需求

同一份笔记生成的文案风格单一，用户希望能根据不同场景选择不同风格：正式干货、轻松口语、情绪共鸣、悬念钩子。

## 设计思路

- 不修改 agent_core.py 的 SYSTEM_PROMPT（保持底层三平台结构不变）
- 在 web_ui.py 中通过笔记前追加风格补充指令，作为用户输入的一部分
- 使用 gr.Radio 组件，四选一，默认"专业干货"

## 核心实现

### 风格指令映射

```python
style_instructions = {
    "专业干货": "",
    "轻松口语": "\n【风格要求：语气像朋友聊天，轻松自然，多用生活化比喻，少讲大道理】",
    "情绪共鸣": "\n【风格要求：开头点出痛点让读者产生共鸣，语气有温度，适当表达焦虑和成就感】",
    "悬念钩子": "\n【风格要求：开头埋悬念钩子，正文逐步揭秘，结尾反转或出人意料】",
}
```

### 生成逻辑

```python
styled_notes = current_notes + style_note if style_note else current_notes
generation_result = agent.run(styled_notes)
```

### 界面组件

```python
style_radio = gr.Radio(
    label="🎨 文案风格",
    choices=["专业干货", "轻松口语", "情绪共鸣", "悬念钩子"],
    value="专业干货",
)
```

## 踩坑记录

1. **返回值数量一致性** — 增加 style 参数后，所有早期 return 语句的返回值数量从 4 个变成 5 个，需要逐一检查补齐

## 使用方法

在配置区选择文案风格，点击生成即可。专业干货为默认，不会追加额外指令。
