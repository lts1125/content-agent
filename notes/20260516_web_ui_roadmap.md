# Web UI 体验改进 Roadmap

## 背景

2025-05-16 Web UI 成功跑通（Gradio 4.44.1 + Python 3.9），基础功能可用：输入笔记 → 选平台 → 生成文案。接下来按优先级逐步打磨体验，为后续内容变现和开源推广做准备。

---

## 改进清单

### P0 - 立即可做，投入小体验提升大

| # | 功能 | 说明 | 状态 |
|---|------|------|------|
| 1 | **实时预览 HTML 卡片** | 输出区嵌入 iframe，直接渲染 html_renderer.py 生成的卡片效果 | ✅ 完成 |
| 2 | **风格模板库** | 预设几种文案风格：专业干货、轻松口语、情绪共鸣、悬念钩子 | 🔲 待做 |
| 3 | **多轮迭代（再改一版）** | 生成后支持输入修改指令，如"更口语化""加个钩子"，上下文继续优化 | 🔲 待做 |
| 4 | **标题 A/B 测试** | 一次生成 3-5 个标题供用户选择 | 🔲 待做 |

## 推荐推进顺序

1. **先做 P0-1（实时预览 HTML 卡片）** — html_renderer.py 已就绪，只差嵌入 UI，半天能搞定
2. **P0-2 + P0-3（风格模板 + 多轮迭代）** — 两个按钮的事，体验质变
3. **P1-5 + P1-6（历史记录 + 批量模式）** — 工作室/矩阵号用户的刚需
4. **P1-8（配图生成）** — 小红书没图等于没发，这个加了价值翻倍
5. 其余按需逐步推进
