😱程序员下班做副业必看！3行代码搭了个AI改写Agent

程序员想做副业，AI Agent 绝对是今年的风口。我自己花了3个晚上，用 PydanticAI 搭了一个能改写小红书/公众号/抖音文案的 Agent，核心代码只有3行👇

🔍 第一步：搞懂 Agent 本质
它不是玄学！= LLM + 工具调用 + 循环
我让它改写文案，它先"思考"原文重点 → "执行"改写 → 不满意就"反思"重写。这就是 ReAct 模式（Reasoning+Acting），听懂掌声👏

⚙️ 第二步：选框架
别一上来就冲 LangChain，太重了！
我对比了三个：
- LangChain：功能全但隐性成本高，适合企业级
- PydanticAI：类型安全、轻量，像写 Rust struct 一样舒服 ✅
- OpenAI Agents SDK：简单但捆绑 OpenAI

🛠 第三步：搭环境
python3 -m venv .venv
pip install pydantic-ai（注意：依赖很多，等了好久）
装 python-dotenv，用 .env 存 DEEPSEEK_API_KEY

🤖 第四步：3行核心代码
1. 定义 model（DeepSeekProvider + OpenAIChatModel）
2. 写 system_prompt（Agent 的灵魂！写得好坏决定输出质量）
3. agent.run_sync(用户输入) 拿结果

💥 踩坑血泪史
❌ PydanticAI 0.8 API 跟文档不一致，OpenAIModel 改名 OpenAIChatModel，不支持直接传 base_url
❌ 结果字段是 result.output 不是 result.data，看源码才发现
❌ Kimi Code 的 API 有 User-Agent 白名单限制，最后切到 DeepSeek

✨ 金句：别把 Agent 想复杂了，它就是个会思考、会工具、会迭代的"打工人"。
