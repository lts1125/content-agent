💻零基础AI Agent开发｜30天搞懂内容改写副业项目

程序员想做副业，AI Agent 是个好方向。我今天刚学完底层套路，手把手给你拆解。

1️⃣ Agent本质：LLM + 工具调用 + 循环循环  
Agent不是魔法，就是让大模型自己思考-执行-反思。比如让我改写小红书文案，它先提取原文重点，再改写，最后检查效果→ReAct模式  

2️⃣ 框架选型：别先碰LangChain  
- LangChain：企业级但太重  
- PydanticAI：类型安全、轻量（我用这个，定义result_type像写Rust struct）
- OpenAI Agents SDK：简单但绑定  
推荐PydanticAI，0.8版文档已更新  

3️⃣ 环境搭建：三步搞定  
```bash
python3 -m venv .venv
pip install pydantic-ai python-dotenv
```
配置.env存DEEPSEEK_API_KEY  

4️⃣ 第一个Agent代码：三行核心逻辑  
```python
model = DeepSeekProvider('openai/gpt-4o-mini')  
agent = Agent(model, system_prompt="你是个改写专家")  
result = agent.run_sync("原文：...")
```
system_prompt是灵魂，写差了一无所有  

5️⃣ 踩坑实录  
- PydanticAI 0.8：OpenAIModel→OpenAIChatModel，传base_url要用Provider包装  
- 结果字段：result.output不是result.data  
- Kimi Code API有User-Agent白名单，切DeepSeek才通  

6️⃣ 下一步计划  
- 加多平台输出模板  
- Pydantic Model定义结构化输出  
- 接入MCP工具协议，自动搜资料补充  

💡金句：Agent开发不是造轮子，是学会让大模型自己跑流程。
