# FeedbackAgent 决策逻辑

> 数据导入后，判断是否更新内容改写策略

---

## 1. 触发条件

### 1.1 自动触发

| 条件 | 阈值 | 说明 |
|------|------|------|
| 样本数量 | >= 5 条 | 足够统计分析 |
| 新数据占比 | >= 30% | 上次分析后新增数据 |
| 时间间隔 | >= 7 天 | 定期刷新 |
| 表现差异 | 新数据平均分与画像差异 > 20% | 趋势变化 |

### 1.2 手动触发

```bash
python main.py --analyze-feedback --platform gongzhonghao
```

## 2. 决策流程

```
导入数据
    |
    v
样本数量 >= 5? --否--> 跳过，继续积累
    |是
    v
计算新数据综合分
    |
    v
与现有画像对比
    |
    v
差异 > 20%? --否--> 跳过，无显著变化
    |是
    v
触发 LLM 分析
    |
    v
更新风格画像
    |
    v
输出优化建议
```

## 3. 更新策略

### 3.1 直接更新

- 更新 style_profiles 表
- 记录更新历史

### 3.2 生成建议报告

```
[FeedbackAgent] 检测到内容表现变化：
- 平均互动率从 5% 上升到 8%
- 高表现内容特征：实用教程类、带代码示例
- 建议：增加技术深度，减少纯概念内容
```

## 4. 与改写流程集成

更新后的风格画像自动影响：
- WriterAgent 的 system prompt
- 各平台风格要求
- 内容长度偏好
