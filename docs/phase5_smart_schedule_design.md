# 智能排期设计文档

> 根据历史数据和平台特性，自动推荐最佳发布时间
> 时间：2026-05-25

---

## 1. 目标

- 分析历史发布数据，找出各平台最佳发布时段
- 根据内容类型推荐发布时间
- 自动设置排期，减少人工决策

## 2. 核心逻辑

### 2.1 数据收集

从 `publish_queue` 和 `content_metrics` 表分析：
- 发布时间 → 阅读量/点赞量/转化率
- 平台差异（小红书/公众号/抖音）
- 内容类型差异（技术/热点/教程）

### 2.2 评分模型

```python
def score_time_slot(platform: str, hour: int, content_type: str) -> float:
    """
    评分逻辑：
    1. 基础分：该平台该时段的历史平均表现
    2. 内容加成：该内容类型在该时段的表现
    3. 竞争减分：该时段已有排期数量
    """
```

### 2.3 推荐规则

| 平台 | 最佳时段 | 原因 |
|------|---------|------|
| 公众号 | 早 8-9 点，午 12-13 点，晚 21-22 点 | 通勤/午休/睡前 |
| 小红书 | 午 11-13 点，晚 19-22 点 | 午休刷/睡前刷 |
| 抖音 | 早 7-9 点，午 12-13 点，晚 18-22 点 | 碎片化时间 |

2. **推荐接口**
   ```python
   def recommend_time(platform: str, content_type: str = "") -> datetime:
       """推荐最佳发布时间"""
   ```

3. **自动排期**
   - 生成内容后自动调用

4. **CLI 命令**
   ```bash

   ```
